# Moonrock’s Café · Mainz-Kastel

Statische Beispielwebsite mit Originalfoto der Lounge, Getränkekarten und responsivem Layout.

## Hosting

GitHub Pages: Branch `main`, Ordner `/ (root)`. Kein Build-Schritt erforderlich. Die Dateien können auch direkt bei einem anderen Anbieter für statische Websites gehostet werden.

## Bearbeiten

- `index.html`: Inhalte und Seitenstruktur
- `style.css`: Gestaltung und responsive Darstellung
- Bilder liegen im selben Verzeichnis.
